## Q-a. Is the ∃-elimination witness a Boolean term in the rigid variables, and in which algebras?

- [S] Martin–Nipkow Lemma 3.3: for any Boolean ring B and a term f with
  constants in B, the equation f(x̄)=0 has a solution in B iff
  f(0,x₂..xₙ)·f(1,x₂..xₙ)=0 has one. Hence it has a solution iff ∏_{b̄∈2ⁿ}
  f(b̄)=0 holds in B. The paper adds that the test is trivial only over 2,
  "otherwise a product may well be 0 even if none of its factors are."
- [S] Martin–Nipkow Theorem 3.4 (Boole's method, successive elimination): given
  a reproductive solution G of the eliminated equation, F(x̄) =
  ((f(0,G)+f(1,G)+1)·x₁ + f(0,G), G) is a reproductive solution. The
  union/complement form is eq. (12): F = (¬f(1,G)·x₁ ∨ f(0,G), G).
- [S] Martin–Nipkow §6.2 also gives a particular solution: if b̄ solves
  f(0,ȳ)f(1,ȳ)=0, then (f(0,b̄), b̄) solves f=0. So the witness is a term built
  from f and the constants.
- [S] Martin–Nipkow Theorem 3.6 (Löwenheim): given any particular solution b̄,
  F(x̄) = x̄ + f(x̄)·(x̄+b̄) is reproductive. In the ∪/¬ form, eq. (13): F =
  x̄·¬f ∨ b̄·f. Wernhard (§6.2) states that Rudeanu 1974 Thm 2.11 is the
  algebraic version and that it is essentially Schröder's *rigorose Lösung*. He
  also cites Rudeanu Lemma 2.3, Lemma 2.2 and Thm 2.2, the last giving the
  solution range ¬F[⊥] ⊨ G ⊨ F[⊤].
- [S] Martin–Nipkow §3: reproductive solutions are most general unifiers, and
  Boolean unification is unitary. Theorem 3.2: solvability in B is equivalent to
  solvability in the finite subalgebra generated by the constants, and an mgu
  there is an mgu in B.
- Assumptions: [S] these results hold in any Boolean ring or algebra B. The free
  algebra is needed only for the zero test, which Martin–Nipkow §5 and Lemma 4.5
  extend to presented algebras. [I] Treating the rigid sets as constants, each
  witness is a term in the rigid variables and the written-label constants, so
  it is a union of Venn regions of them.

## Q-b. Is positive ∀∃ validity the same as an identity checkable on {0,1}?

- [S] Wernhard Prop. 19 with Prop. 15: for propositional F, the solution problem
  F[p] has a solution iff ∃p F is valid. Wernhard §5.3, citing Schröder vol. 1
  §21 and Rudeanu 1974 p. 62: ∃p F is valid iff the elimination result (the
  *Resultante*) is valid.
- [S] Martin–Nipkow Theorem 4.1 (Stone): Boolean rings are exactly the subdirect
  powers of 2. [I] Consequently an equation holds identically in a nontrivial
  Boolean algebra iff it holds in 2.
- [I] Applying Lemma 3.3 inside the universal turns ∀X̄. d(X̄)=0 ⇒ ∃Ȳ f=0 into
  the universal Horn sentence ∀X̄. d=0 ⇒ g=0, where g = ∏_{b̄} f(X̄,b̄). That
  sentence is preserved under subalgebras (2 ⊆ B). It holds in 2 iff g ≤ d
  pointwise on {0,1}ⁿ, and that identity implies the sentence in every BA. So
  for a nontrivial B, validity in B is the same as g ≤ d checked on {0,1}ⁿ.
- [C] The split example gives g ≤ d on 2³. The §6.2 witness evaluates to u = r∖s
  and v = r∩s, it solves the system wherever s∩t=0, and it is empty outside
  r∪s∪t.
- Caveats:
  - **Finite–cofinite algebra vs. powerset.** [S] Jeřábek Thm 3 (attributed to
    Skolem): two atomic BAs are elementarily equivalent iff they have the same
    number of atoms, or both have infinitely many. [S] Jeřábek Ex. 8: Inv(P(X))
    = ⟨0,|X|,0⟩. [I] The finite–cofinite algebra over ℕ is atomic with
    infinitely many atoms, so it is elementarily equivalent to P(ℕ), even for
    formulas with negation.
  - **Rows must be finite.** [I] The finite subsets of an infinite set form a
    Boolean ring without unit, so they are not a BA. None of the sources read
    discusses this setting. If the atoms use no top constant, every term
    vanishes at all-zero inputs, and the eliminant only multiplies by f(…,0)
    factors. My conjecture is that the witnesses stay inside the union of the
    rigid sets and the constants. The split check agrees with this, but it is
    unproven.
  - **Written labels are constants.** [S] Martin–Nipkow Lemma 4.5 / Ex. 4.6: in
    a presented algebra, p = 0 iff p·W = 0 in the free algebra, where W =
    ∏(wᵢ+1). [I] The relations cᵢcⱼ = 0 can be added this way. However, "cᵢ ≠ 0"
    and "cᵢ is an atom" are not equations. Here is a counterexample to the plain
    free check: ∀X. c=0 ⇒ X=0 is vacuously valid when c is a singleton, but X ≤
    c fails on 2 [C]. So when the hypotheses can contradict cᵢ ≠ 0, the identity
    check is sound but not complete. In the other cases a region argument
    suggests atomicity does not matter for positive formulas. This is
    unverified.

## Q-c. What changes with negated atoms or cardinality?

- [S] KNR TR §2: constant-cardinality atoms |A| ≥ C "enable quantifier
  elimination for the resulting language" (citing Löwenheim 1915 and Skolem
  1919). [S] Jeřábek Thm 3: over atomic BAs, every formula is equivalent to a
  propositional combination of |x̄ᵉ| ≥ s. [S] Jeřábek Thm 17 covers all BAs,
  which need extra invariants (level, atomless part). Thm 2: the theory of
  atomless BAs has quantifier elimination without counts.
- [S] KNR Lemma 1 / Fig. 10: ∃y over disjoint cubes bᵢ with |bᵢ∩y| = kᵢ and
  |bᵢ∖y| = lᵢ reduces to |bᵢ| = kᵢ+lᵢ, so eliminating a set quantifier produces
  sums of counts. §10 / Lemma 7 adds fin(·) to handle an infinite universe.
- [I] Here is why counts appear. With ≠, ∃y. y⊆x ∧ y≠0 ∧ y≠x says |x| ≥ 2, which
  no equation in x can express. Positive equations only ever ask whether a
  region is empty, which is the 2-valued case.

## Q-d. Complexity

- [S] Martin–Nipkow §7: the eliminated term has length O(l·2ⁿ). The zero test
  costs O(m·l·2ⁿ), where m is the number of basis atoms. In the free ring on k
  constants this is O(l·2^{k+n}). Boole's and Löwenheim's methods have the same
  bound. The text adds: "a practical implementation requires the judicious
  application of simplifications every time a variable is eliminated." Finding
  particular solutions is NP-complete.
- [S] Wernhard §5.1, citing Baader 1998 and Kapur–Narendran: Boolean unification
  with constants is Π₂ᴾ-complete.
- [S] KNR Thm 6: pure BA sentences can be decided in O(nS·2^S) space. Kozen
  1980, as reported in a search snippet only: the first-order theory of BAs is
  complete for alternating 2^{cn}-time with n alternations.
- [I] The problem class here is a single ∀∃ alternation with equations only.
  That is the Π₂ᴾ shape, and checking the identity on {0,1} is a coNP tautology
  check after elimination.
